# 🚀 Kotlin Learning Journey

Welcome to my **Kotlin Learning** repository! This project contains a collection of my fundamental Kotlin programming practice codes, syntax experiments, and basic concepts learned using IntelliJ IDEA.

Before diving into native Android development and Jetpack Compose, I used this workspace to build a strong foundation in the Kotlin programming language.

## 📂 Project Structure

All the practice source codes are located inside the `src/Kotlin/Basic` directory.

## 📚 Topics Explored

This repository serves as a reference for core Kotlin concepts, including:
*   Variables & Data Types
*   Control Flow (`if/else`, `when`, loops)
*   Functions & Lambdas
*   Object-Oriented Programming (Classes, Objects, Inheritance)
*   Null Safety features
*   Collections (Lists, Sets, Maps)

## 🛠️ Tools & Technologies

*   **Language:** Kotlin
*   **IDE:** IntelliJ IDEA
